# دليل المستخدم — صفحة الإشعارات المتكررة
# User Guide — Recurring Notification Triggers

> **من يستخدم هذه الصفحة؟**  
> هذه الصفحة مخصصة للمشرفين ومديري الفريق فقط. المستخدمون العاديون والمرضى لا يشاهدونها.  
>
> **Who uses this page?**  
> Admins and Coach Managers only. Regular users and patients never see this screen.

---

## 📌 ما هو الإشعار المتكرر؟ / What is a Recurring Trigger?

الإشعار المتكرر هو **حملة إشعارات مجدولة** تُرسَل تلقائياً في أوقات محددة لمجموعة مستهدفة من المستخدمين.  
A recurring trigger is a **scheduled notification campaign** that fires automatically at configured times to a target audience.

**أمثلة / Examples:**
- إرسال تذكير أسبوعي للأطباء كل يوم اثنين الساعة 8 صباحاً
- إرسال تهنئة عيد ميلاد يومية لجميع المرضى الساعة 9 صباحاً
- إرسال ملخص شهري للمشرفين في أول كل شهر

## 🖥️ الشاشة الرئيسية — قائمة الإشعارات / Main Screen — Trigger List

عند فتح الصفحة، ستجد جدولاً بجميع الإشعارات المتكررة المُعَدَّة.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  🔔 Recurring Notifications          3 active of 5          [+ New trigger] │
├──────────┬──────────────────────┬──────────────┬─────────────────┬──────────┤
│  Active  │       Title          │   Category   │    Schedule     │ Audience │
├──────────┼──────────────────────┼──────────────┼─────────────────┼──────────┤
│   ✅ ON  │ Weekly Digest        │ Session Book │ Every week Mon  │ Doctors  │
│   ⭕ OFF │ Birthday Greetings   │ Birthday     │ Every day 09:00 │ Patients │
└──────────┴──────────────────────┴──────────────┴─────────────────┴──────────┘
```

### أعمدة الجدول / Table Columns

| العمود | الوصف |
|--------|--------|
| **Active** | مفتاح تشغيل/إيقاف الإشعار — يمكنك تفعيله أو إيقافه مباشرةً من هنا |
| **Title** | اسم الإشعار — اضغط عليه لفتح شاشة التعديل |
| **Category** | نوع الإشعار (حجز جلسة، تأكيد، إلخ.) |
| **Schedule** | توقيت التشغيل، مثل "Every week on Mon at 08:00" |
| **Audience** | المستهدفون، مثل "Doctor, Coach, 2 user(s)" |
| **الأزرار** | ✏️ تعديل — 🗑️ حذف |

> **ملاحظة:** النص في عمودَي Schedule وAudience يظهر كما أرسله السيرفر مباشرةً.

- الشريط البرتقالي يمثل نسبة النشطة بصرياً

| النوع | الاستخدام الموصى به |

| نتائج قياسات — Measurement Results | إشعار بنتائج القياسات |
| نزول تقرير — Report Released | إشعار صدور التقارير |

### القسم الثاني: Schedule Rule — قاعدة الجدولة

```
┌─────────────────────────────────────────────────┐
│  Schedule Rule                                  │
│                                                 │
│  Frequency                                      │
│  Repeats:  [Daily]  [Weekly]  [Monthly]         │
│                                                 │
│  Every:   [1] ▲▼   day(s) / week(s) / month(s) │
│                                                 │
│  (Weekly only) On days:                         │
│  [Su] [Mo] [Tu] [We] [Th] [Fr] [Sa]            │
│                                                 │
│  (Monthly only) On day:  [15]                   │
│                                                 │
│  ─────────────────────────────────────────────  │
│  Timing                                         │
│  At:        [08:00]                             │
│  Starting:  [Sep 15, 2026]                      │
│  ─────────────────────────────────────────────  │
│  Ends                                           │
│  ○  Never                                       │
│  ○  On date     [Dec 31, 2026]                  │
│  ○  After       [5]  sends                      │
└─────────────────────────────────────────────────┘
```

#### تكرار الإرسال / Frequency

| الخيار | المعنى | الحقول الإضافية المطلوبة |
|--------|--------|--------------------------|
| **Daily** | كل يوم (أو كل N أيام) | لا يوجد |
| **Weekly** | أسبوعياً — حدد الأيام | **On days** (اختر يوماً واحداً على الأقل) |
| **Monthly** | شهرياً — حدد يوم الشهر | **On day** (رقم بين 1 و31) |

> ⚠️ **ملاحظة للأيام الأسبوعية:** الأحد = `Su` (أول الأسبوع في النظام) — هذا النظام المستخدم في قاعدة البيانات.

#### حقل "Every" — الفترة

يحدد **كل كم** يُرسَل الإشعار:
- `1` = كل يوم / كل أسبوع / كل شهر
- `2` = كل يومين / كل أسبوعين / كل شهرين

#### توقيت الإرسال / Timing

| الحقل | الوصف |
|-------|--------|
| **At** | وقت الإرسال بالتوقيت المحلي للعيادة (24 ساعة) — مثال: `08:00` |
| **Starting** | تاريخ بداية الجدولة — لن يُرسَل الإشعار قبل هذا التاريخ |

> ⚠️ **الوقت بالتوقيت المحلي للعيادة** — وليس UTC.

#### متى ينتهي الإشعار / Ends

| الخيار | المعنى |
|--------|--------|
| **Never** | يستمر إلى ما لا نهاية حتى يُحذف أو يُوقَف يدوياً |
| **On date** | يتوقف تلقائياً في التاريخ المحدد (يجب أن يكون بعد تاريخ البداية) |
| **After N sends** | يتوقف بعد إرساله عدداً محدداً من المرات — السيرفر يُوقِفه تلقائياً |

### القسم الثالث: Target Audience — الجمهور المستهدف

```
┌─────────────────────────────────────────────────────┐
│  Target Audience                                    │
│                                                     │
│  Target staff roles                                 │
│  ┌───────────────────────────────────────────┐      │
│  │  [Doctor x]  [Coach x]      Select...  ▼ │      │
│  └───────────────────────────────────────────┘      │
│                                                     │
│  Include all patients          ┌──┐                 │
│  Send to every active account  │●●│ ON              │
│                                └──┘                 │
│                                                     │
│  Specific individual recipients                     │
│  ┌───────────────────────────────────────────┐      │
│  │  [Ahmed Mohamed x]      Search users...  │      │
│  └───────────────────────────────────────────┘      │
│                                                     │
│  ┌─ Target audience ─────────────────────────┐      │
│  │  2 roles  •  All patients  •  1 individual│ INFO │
│  └───────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────┘
```

#### خيارات الجمهور / Audience Options

| الخيار | الاستخدام |
|--------|-----------|
| **Target staff roles** | اختر دوراً أو أكثر من الموظفين (طبيب، مدرب، ممرض، إلخ.) |
| **Include all patients** | أرسل لجميع المرضى النشطين في النظام |
| **Specific individual recipients** | ابحث عن مستخدمين بعينهم وأضفهم لقائمة المستلمين |

> ⚠️ **قاعدة إلزامية:** يجب اختيار **خيار واحد على الأقل** من الثلاثة.  
> إشعار بدون جمهور مرفوض من السيرفر بخطأ.

- يمكنك **الجمع بين الخيارات الثلاثة** معاً.
- شريط **"Target audience"** يُظهر ملخصاً فورياً لما اخترته.
- إذا لم يُختَر شيء → تحذير أصفر `"Nobody selected yet"`.

#### المسميات الوظيفية / Staff Roles

| الاسم | الدور |
|-------|-------|
| Doctor | طبيب |
| Coach Manager | مدير مدرب |
| Coach | مدرب |
| Nurse | ممرض/ة |
| Receptionist | موظف استقبال |
| Admin | مشرف النظام |

### القسم الرابع: Trigger is Active — تفعيل الإشعار

```
┌─────────────────────────────────┐
│  ┌──┐  Trigger is active        │
│  │●●│  Inactive triggers are    │
│  └──┘  saved but will never fire│
└─────────────────────────────────┘
```

| الحالة | المعنى |
|--------|--------|
| **Active (ON)** | نشط ويُرسَل في المواعيد المحددة تلقائياً |
| **Inactive (OFF)** | محفوظ لكنه لن يُرسَل أبداً — مفيد للإعداد المسبق |

---

### حفظ الإشعار / Saving

```
                         [Cancel]   [✔ Save Trigger]
```

- **Save Trigger** → يحفظ ويعود لقائمة الإشعارات مباشرةً.
- **Cancel** → يرجع للقائمة بدون حفظ.
- إذا ظهر خطأ باللون الأحمر في أعلى النموذج → اقرأ الرسالة وصحح البيانات.

## ✏️ تعديل إشعار موجود / Editing an Existing Trigger

1. اضغط على **اسم الإشعار** في الجدول أو على زر **✏️** بجواره.
2. تُفتح نفس شاشة النموذج محمّلةً ببيانات الإشعار الحالية.
3. عدّل ما تريد → اضغط **Save Trigger**.

> **معلومة:** في وضع التعديل يظهر أيضاً عدد مرات الإرسال الفعلية وتاريخ آخر إرسال.

---

## 🔄 تفعيل / إيقاف بسرعة / Quick Toggle

**مباشرةً من الجدول** بدون دخول النموذج:

1. ابحث عن الإشعار في الجدول.
2. اضغط على **مفتاح التشغيل** في عمود "Active".
3. يتغير الوضع فوراً (✅ → ⭕ أو العكس).

> إذا حدث خطأ في السيرفر، يرجع المفتاح لوضعه السابق تلقائياً.

---

## 🗑️ حذف إشعار / Deleting a Trigger

1. ابحث عن الإشعار في الجدول.
2. اضغط على زر **🗑️** في نهاية الصف.
3. يُحذف الإشعار فوراً والقائمة تتحدث.

> ⚠️ **تحذير:** الحذف نهائي ولا يوجد تأكيد.  
> **بديل أفضل:** أوقف الإشعار (Active = OFF) بدلاً من حذفه إذا كنت قد تحتاجه مستقبلاً.

## ⏱️ كيف يصل الإشعار للمستخدم؟ / Delivery Flow

```
Admin يضغط Save
         │
         ▼
   [السيرفر يحفظ الـ Trigger]
         │
         ▼
   [Background Job يفحص كل ~1 دقيقة]
         │
    الآن وقت الإرسال؟
         │
    نعم ──────► يُرسل الإشعار لكل شخص مستهدف
                        │
               ┌────────┴────────┐
               ▼                 ▼
          REST Feed           SignalR
     (يظهر في الجرس 🔔)   (يصل فوري real-time)
```

**نقاط مهمة:**
- لا يوجد زر "إرسال فوري" — السيرفر يُرسَل في الوقت المحدد فقط.
- كل إشعار لا يُرسَل أكثر من مرة في نفس اليوم حتى لو تم تعديله.
- الإشعار الواصل للمستخدم يكون نوع **RecurringTrigger** في الـ feed.
- إذا اخترت **"After N sends"** والإشعار وصل للحد → السيرفر يُوقِفه تلقائياً.

## ❓ أسئلة شائعة / FAQ

**س: عملت إشعار ولم يصل في الوقت المحدد؟**  
ج: قد يتأخر حتى دقيقة. تأكد أن الإشعار **Active** وأن **تاريخ البدء** مر بالفعل.

**س: قمت بتعديل الإشعار وأعدت تشغيله — هل يُرسَل مرة ثانية نفس اليوم؟**  
ج: لا. كل إشعار لا يُرسَل أكثر من مرة في اليوم الواحد مهما حدث.

**س: اخترت Weekly لكن لم أختر أياماً — ماذا سيحدث؟**  
ج: السيرفر سيرفض الحفظ بخطأ. لازم تختار يوماً واحداً على الأقل.

**س: اخترت Monthly بيوم 31 — ماذا يحدث في فبراير؟**  
ج: السيرفر يُرسِل في آخر يوم في الشهر تلقائياً (28 أو 29 فبراير).

**س: أريد إرسال الإشعار لأشخاص محددين فقط؟**  
ج: استخدم **"Specific individual recipients"** وابحث عن أسمائهم.

**س: الإشعار أُوقِف تلقائياً ولم أفعل ذلك — لماذا؟**  
ج: الإشعار استنفد عدد الإرسالات المحدد في **"After N sends"**.

## 🔑 ملخص سريع / Quick Reference

```
لإنشاء إشعار جديد:
1. اضغط [+ New trigger]
2. اكتب العنوان والرسالة واختر النوع
3. حدد التكرار (يومي / أسبوعي / شهري) والوقت والتاريخ
4. حدد متى ينتهي (أبداً / تاريخ / عدد مرات)
5. اختر الجمهور (دور / مرضى / أشخاص بعينهم)
6. تأكد من وضع المفتاح (Active ON لتفعيله فور الحفظ)
7. اضغط [✔ Save Trigger]
```
